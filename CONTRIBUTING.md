# Contributing

Found a shields.io badge for a technology that isn't listed yet? Contributions are welcome.

## Adding a badge

1. Fork the repository
2. Add the badge under the matching category section (or propose a new category)
3. Keep the same visual style (`style=for-the-badge` for header badges, `style=flat-square` for category badges)
4. Update the total badge/category counters in the intro if they changed
5. Open a Pull Request

## Guidelines

- Only add real, working shields.io (or equivalent) badges
- Keep categories alphabetically sensible within their section
